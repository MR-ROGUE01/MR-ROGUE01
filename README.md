## 🚀 Featured Projects

### 🫁 Sleep-Disordered Breathing Detection
> Python · scikit-learn · NumPy · pandas · SciPy · Optuna · Machine Learning

Developed an end-to-end Machine Learning pipeline for detecting **Sleep-Disordered Breathing** using physiological features extracted from overnight sleep recordings. Performed data preprocessing, exploratory data analysis (EDA), feature engineering, label encoding, and model comparison across multiple ML algorithms. Optimized the best-performing model using **Optuna** and built a deployment-ready Scikit-learn pipeline. The final model classifies **Normal**, **Hypopnea**, and **Obstructive Apnea** events with **96.4% test accuracy**.

**Key Highlights**
- 📊 Comprehensive EDA and feature analysis
- ⚙️ Data preprocessing and feature engineering
- 🤖 Compared multiple Machine Learning models
- 🎯 Hyperparameter tuning using Optuna
- 💾 Deployment-ready Scikit-learn Pipeline
- 📈 Achieved **96.4% test accuracy**

[View Repo →](https://github.com/MR-ROGUE01/sleep-disordered-breathing-detection)

### 🚢 End-to-End Titanic Survival Pipeline
> Python · scikit-learn · pandas · Pickle

5-stage leakage-free `sklearn.Pipeline`: ColumnTransformer imputation → OneHotEncoder → MinMaxScaler → SelectKBest(chi², k=5) → DecisionTreeClassifier. Single `.fit()` / `.predict()` call. **63.9% mean CV accuracy (5-fold)**. Serialized via Pickle for one-line inference deployment.

[View Repo →](https://github.com/MR-ROGUE01/end-to-end-titanic-survival-pipeline)
